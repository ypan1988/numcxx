# Internal Documentation

The files in this directory describe NumCxx implementation details. They may cover both public APIs and non-public APIs used internally by the library.

Public APIs may be used as documented by the NumCxx public interface. Non-public APIs are implementation details, are not part of the stable public interface, and should not be used by application code. They may change without notice.

## Documents

- [Slice](slice.md): Describes the public `slice` API and its internal normalization support.
